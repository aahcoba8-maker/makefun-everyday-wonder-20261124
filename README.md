# Everyday Wonder, Two Days to Find the Line

One sentence, up to 200 characters, that makes a small everyday moment strange and new.

## Entry

The lift doors opened on the wrong floor, and the stranger inside was humming my dead grandmother's lullaby, note for note.

## How it works

`main.py` (Python standard library only) writes the entry sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to the script directory).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
